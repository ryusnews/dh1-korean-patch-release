# 대항해시대1 한글패치 (Uncharted Waters, DOS)

영문 DOS판 **대항해시대(Uncharted Waters, KOEI 1990)** 를 한글로 옮기고, 원작의 불편한 점을 덜어 주는 편의 기능을 더한 비공식 팬 패치입니다.

> 이 저장소와 배포 파일에는 **원작 게임 파일이 들어 있지 않습니다.** 패치는 바뀐 바이트와 체크섬만 담고 있으며, 가지고 계신 원본 게임에 적용해서 씁니다.

---

| 구분 | 내용 |

| 항해 편의 | 숫자 패드 침로 지정, 항해 속도 조절(1~10), 자동 항해 |

| 능력 편집 | 안식의 신전에서 자신·부하·항구 값 편집, 지도 전체 공개 |

| 설치 | 원본 검증 → 차이 적용 → `*.ORG` 백업 → 되돌리기 지원, 기존 세이브 변환 |

## 1. 한글화

- **번역 범위**: `MAIN.EXE` 1,773개, `OPEN.EXE`(오프닝) 123개, `END.EXE`(엔딩) 35개, 모두 1,931개 문장을 옮겼습니다.
  항구·인물·상품·아이템 이름, 메뉴, 대화, 소문, 전투 메시지, 국왕 임무, 공주 이벤트 등이 들어갑니다.
- **용어집**을 두어 항구·상품·작위 이름이 화면마다 같게 나오도록 했습니다.
- **한글 출력 방식**
  - 원작은 EGA 640×200 화면에 8×8 BIOS 글꼴로 글자를 그립니다. 글자 그리기 루틴(drawchar)을 고쳐 한글 한 글자를 16×8(영문 두 칸)로 그립니다.
  - 한글 글꼴은 상주 프로그램 `HANFONT.COM`(int 61h)이 맡습니다. `FMDRV.COM`이 쓰는 int 66h와 겹치지 않게 했습니다.
  - 원작 문자열 처리에 남아 있는 Shift-JIS 2바이트 처리와 충돌하지 않도록 자체 2바이트 인코딩(완성형 2,350자)을 씁니다.
  - 글꼴은 **갈무리(Galmuri7)** 7픽셀 글꼴을 가로로 두 배 늘려 16×8로 변환했습니다.
- **문장 길이 제약 해결**: 번역문이 원래 자리보다 길면, 문자열을 빈 공간으로 옮기고 가리키는 포인터를 고쳐 줍니다. 세이브에 함께 저장되는 영역의 문자열은 자리를 옮기지 않고 그 안에 맞춥니다.
- `MAIN.EXE` / `OPEN.EXE` / `END.EXE`는 EXEPACK으로 압축되어 있어서 먼저 풀어낸 뒤 패치합니다.

## 2. 항해 편의 기능

### 숫자 패드 침로 지정
항해 중 숫자 패드로 방향을 바로 바꿉니다. 침로 설정 화면에서도 같은 키를 씁니다.

```
7 북서   8 북   9 북동
4 서            6 동
1 남서   2 남   3 남동
```

### 항해 속도 조절 (1~10)
- 1이 가장 빠르고, 5가 원작 속도, 10이 가장 느립니다.
- 바다 명령 메뉴에 새로 넣은 **[속도]**, 또는 안식의 신전 메뉴의 **[항해 속도]** 에서 바꿉니다.
- 항해 중에만 적용되고, 항구·전투·메시지는 원작 속도 그대로입니다.
- 값은 세이브에 함께 저장됩니다.

### 자동 항해
- **세계지도 → 확대 화면**에서 이미 발견한 항구에 커서를 두고 `Enter`를 누르면 그 항구까지 배가 알아서 갑니다.
- 도착하면 닻을 내리고, 게임이 원래대로 "기항지는 ○○. 괜찮습니까?"를 물어 바로 입항할 수 있습니다.
- 항해 중 아무 키나 누르면 **"자동 항해를 취소할까요?"** 를 묻고 멈출 수 있습니다.
- 항로는 시대에 맞게 계산했습니다.
  - 기본적으로 해안을 따라가고, 육지에서 멀어질수록 먼 바다를 피합니다.
  - 대양은 역사 속 항로를 따라 건넙니다: 카레라 함대 항로(왕복), 인도 항로(카헤이라 다 인디아)와 볼타 두 마르, 인도양 계절풍 항로, 마닐라 갤리온 항로(동·서). 가는 방향과 오는 방향을 따로 봅니다.
- 항로 데이터(`FLOW.DAT`)는 패치할 때 사용자의 원본 지도 데이터(`NEWGAME.DAT`)로 만듭니다. 70개 항구 각각에 대해 바다 모든 칸에서 갈 방향을 미리 계산해 둡니다.

## 3. 세계지도

- 바다 명령의 **[보기]** 메뉴에 **[세계지도]** 를 추가했습니다. 원작의 [지도](현재 해역만 보임)는 그대로 둡니다.
- **전체 지도 → 확대 지도** 두 단계로 봅니다.
  - 전체 지도: 방향키 이동, `Enter` 확대, `0`/`ESC` 닫기
  - 확대 지도: `Enter` 자동 항해, `0` 뒤로
- **안개(전장의 안개)**: 배가 지나간 곳만 지도에 드러납니다. 망원경이 있으면 더 넓게 보입니다. 새로 드러난 곳의 항구는 발견한 항구로 표시됩니다.
- **육분의**가 있으면 커서 위치의 위도·경도(북위/남위, 동경/서경)를 보여 줍니다.
- 지도 화면은 게임의 해도 패널과 어울리게 양피지 테두리로 꾸몄고, 장식(덩굴무늬, 나침반)은 게임 화면에서 그대로 가져옵니다.
- 탐험 기록은 세이브 슬롯별로 `FOGMAP.DAT`에 저장됩니다. 이 기능 전에 만든 세이브는 이미 발견한 항구 주변을 밝힌 상태로 시작합니다.
- 지도 데이터(`WMAP.DAT`)도 패치할 때 사용자의 원본 파일로 만듭니다.

## 4. 보급 편의

- 항구 보급 메뉴에 **[자동 보급]** 과 **[보급 설정]** 을 추가했습니다.
- **보급 설정**: 배마다 물·식량·목재의 목표량을 정해 둡니다(세이브에 저장).
- **자동 보급**: 모든 배를 목표량까지 한 번에 채웁니다. 배의 남은 적재 공간과 소지금 안에서만 사고, 가격은 그 항구 기준으로 계산합니다. 끝나면 보급한 양과 비용을 알려 줍니다.

## 5. 능력 편집 (안식의 신전)

오프라인 플레이용 편집 기능입니다. 안식의 신전 메뉴에 **[능력 편집]** 을 추가했습니다.

| 대상 | 편집 항목 |
|---|---|
| 자신 | 능력치(통솔력·판단력·지력·용기·강인함·나이), 소지금, 명성, 작위, 전투·항해 경험과 레벨 |
| 부하 | 능력치, 나이, 충성도, 전투·항해 경험과 레벨 (부하 일람에서 선택) |
| 항구 | 지금 있는 항구의 경제력·공업력과 수익, 나라별 지지도(포르투갈·스페인·터키), 시세 |
| 지도 공개 | 세계지도의 안개를 모두 걷기 / 다시 켜기 |

바꾼 값은 신전에서 저장해야 세이브에 남습니다.

## 6. 화면·표시 개선

- 보급 화면에서 한글 단위 뒤에 붙던 영어 복수형 `s`를 없앴습니다.
- 최대 적재량 줄에 통 단위 값을 함께 보여 줍니다(예: `통(N)`).

## 7. 설치 도구 (패처)

- `DH1_KoreanPatch.exe` 하나로 적용합니다(Windows GUI, 명령줄 `--cli 폴더 apply|restore` 도 지원).
- 적용 전에 원본 파일을 SHA-256으로 확인합니다. 지원 판본(영문 DOS판, `MAIN.EXE` 338,277바이트)이 아니면 아무것도 바꾸지 않습니다.
- 원본은 `*.ORG`로 자동 보관되고, **[되돌리기]** 로 원래대로 돌릴 수 있습니다.
- 이전 버전 패치가 적용된 폴더도 `*.ORG`에서 바로 최신 버전으로 올립니다.
- **기존 세이브 변환**(선택): 이미 저장된 게임의 항구·인물·아이템 이름을 한글로 바꿉니다. 게임 중 바뀐 값이나 직접 입력한 이름은 건드리지 않습니다. 원본은 `SAVE.DAT.ORG`로 보관됩니다.
- 배포 패치(`KOPATCH.DAT`)에는 원작 코드 없이 바뀐 바이트와 체크섬만 들어 있습니다.

## 설치와 실행

**[최신 버전 내려받기 (Releases)](../../releases/latest)** 에서 `DH1_KoreanPatch_v1.7.zip`을 받아 압축을 풉니다.

1. `DH1_KoreanPatch.exe`를 게임 폴더(`MAIN.EXE`, `KOEI.COM`이 있는 곳)에 넣고 실행합니다.
2. 상태가 모두 "원본"인지 확인하고 **[패치 적용]** 을 누릅니다.
3. 게임 폴더에서 `KOREAN.BAT`로 실행합니다.
   - DOSBox / DOSBox-X: 게임 폴더를 마운트한 뒤 `KOREAN.BAT`
   - DGGL 등 실행기: 실행 명령을 `KOEI.COM` 대신 `KOREAN.BAT`로 바꿉니다.

`KOREAN.BAT`는 한글 글꼴 상주 프로그램 `HANFONT.COM`을 먼저 올린 뒤 게임을 시작합니다. `KOEI.COM`으로 바로 실행하면 한글이 깨집니다.

### 패치 후 늘어나는 파일

| 파일 | 내용 |
|---|---|
| `HANFONT.COM` | 한글 글꼴 + 새 기능(침로, 속도, 세계지도, 자동 항해, 보급, 편집) 상주 프로그램 |
| `KOREAN.BAT` | 실행용 배치 파일 |
| `WMAP.DAT` | 세계지도 데이터 (원본 `NEWGAME.DAT`로 생성) |
| `FLOW.DAT` | 자동 항해 항로 데이터 (원본 `NEWGAME.DAT`로 생성, 약 17MB) |
| `FOGMAP.DAT` | 세이브 슬롯별 탐험 기록 (게임 중 생성) |
| `*.ORG` | 원본 백업 |

## 알려진 사항

- 주인공·배 이름 입력은 영문만 됩니다(원작 입력 화면 그대로).
- 실제 DOS PC에서도 동작하지만 기본 메모리가 약 40KB 더 필요합니다.
